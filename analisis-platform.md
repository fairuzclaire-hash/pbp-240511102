Refleksi

Dari beberapa platform pengembangan, saya paling tertarik dengan Web. Alasannya sederhana, cukup dengan HTML, CSS, dan JavaScript,
kita sudah bisa membuat aplikasi yang langsung bisa dibuka di browser tanpa diinstal dulu. Saya juga penasaran bagaimana sebuah
website dirancang supaya tampilannya enak dilihat, menyesuaikan ukuran layar, dan nyaman dipakai. Kalau kemampuan ini sudah terasah,
rasanya akan berguna untuk proyek proyek saya ke depan.

Tantangan terbesar saat setup environment buat saya adalah memastikan semua tools benar benar terpasang dan bisa jalan. Ada Git, Node.js, NPM, Java JDK, dan Visual Studio Code,
dan fungsinya beda beda, jadi saya harus paham dulu untuk apa tiap tools itu dipakai. Belum lagi kalau ada error konfigurasi atau perintah di terminal gagal. Karena saya belum
terbiasa dengan terminal, hal seperti itu gampang bikin bingung.

Ke depannya, saya mau mempelajari tools tersebut satu per satu lewat dokumentasi resmi dan tutorial yang mudah dipahami. Setelah instal,
saya akan cek versinya lewat terminal untuk memastikan semuanya berhasil. Kalau ada kendala, saya baca dulu pesan errornya,
lalu cari penyebabnya di dokumentasi. Kalau masih buntu, saya akan bertanya kepada dosen atau teman. Harapannya,
saya jadi lebih paham lingkungan pengembangannya dan lebih mandiri di proyek berikutnya.
